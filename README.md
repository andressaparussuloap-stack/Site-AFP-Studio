# 💜 AFP Studio

### Sites personalizados para pequenos negócios

A **AFP Studio** é um projeto voltado ao desenvolvimento de sites personalizados para pequenos negócios e profissionais que desejam fortalecer sua presença digital.

O objetivo é criar páginas modernas, responsivas e visualmente atraentes, valorizando a identidade de cada negócio.

---

## 🚀 Sobre o projeto

Este repositório contém o site institucional da AFP Studio, desenvolvido para apresentar os serviços oferecidos, exibir projetos do portfólio e facilitar o contato com potenciais clientes.

### ✨ Funcionalidades

- Página inicial com apresentação da marca.
- Seção de serviços.
- Apresentação da AFP Studio.
- Portfólio de projetos.
- Botão de contato pelo WhatsApp.
- Layout adaptável para computadores, tablets e celulares.
- Identidade visual com preto, roxo e branco.

## 🎨 Identidade visual

A identidade visual da AFP Studio utiliza uma combinação de cores para transmitir modernidade, criatividade e profissionalismo.
